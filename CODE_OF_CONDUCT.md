# Kode Etik / Code of Conduct

## Komitmen / Our pledge

Kami ingin proyek ini ramah dan bebas pelecehan bagi semua orang, apa pun usia, latar belakang, gender, kemampuan, atau tingkat
pengalaman.
We want this project to be welcoming and harassment-free for everyone, regardless of age, background, gender, ability or experience.

## Perilaku yang diharapkan / Expected behavior

- Bersikap sopan, menghargai, dan konstruktif; kritik ide, bukan orangnya. / Be respectful and constructive.
- Menerima umpan balik dengan lapang dada. / Accept feedback graciously.
- Membantu pemula. / Help newcomers.

## Perilaku yang tidak dapat diterima / Unacceptable behavior

- Pelecehan, hinaan, ancaman, diskriminasi, atau komentar merendahkan. / Harassment, insults, threats, discrimination.
- Membocorkan data pribadi orang lain tanpa izin. / Publishing others' private information.
- Spam atau promosi tidak relevan. / Spam or off-topic promotion.

## Penegakan / Enforcement

Pemelihara proyek berhak menghapus komentar, menutup issue/PR, atau memblokir kontributor yang melanggar. Laporkan pelanggaran
lewat [GitHub Security Advisory / kontak pemilik](https://github.com/rhmt25) atau email pemilik repositori di profil GitHub.
Maintainers may remove comments, close issues/PRs, or block contributors who violate this code. Report to the repository owner
via their GitHub profile.

Kode etik ini diadaptasi secara ringkas dari semangat [Contributor Covenant](https://www.contributor-covenant.org/) v2.1.
